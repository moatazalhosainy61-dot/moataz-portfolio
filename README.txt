Moataz Portfolio — README

How to use:
- Unzip this folder.
- Open index.html in a browser to preview locally.
- To add projects later: put images into projects/data/ or projects/design/ and update images.json or rely on fallback.
- Certificates: add images in projects/certificates/ and update images.json.
- To publish: create a GitHub repository, upload all files (root must contain index.html), then enable GitHub Pages (Settings -> Pages -> Deploy from a branch -> main / root).

Included files:
- index.html, style.css, script.js
- IMG_profile.jpeg (profile) if present will display in header (you can replace it later)
- moataz cv.pdf
- projects/data/ (contains images.json and data images)
- projects/design/ (empty)
- projects/certificates/ (empty)
